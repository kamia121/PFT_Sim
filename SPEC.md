# PFT_Sim specification

Revision 2. This revision replaces the scope memo with an implementable specification. Every clinical threshold, criterion and coefficient in it carries a source column and a verification state. Nothing marked "unverified" may be coded until someone has read the primary source and recorded the check next to the value.

## Status

Implemented and tested: scaffold; seeded PRNG with named streams; descriptor and URL codec; volume-time curve family; maneuver-set generator with the 2019 acceptability and grading rules; the GLI reference module validated against rspiro; constructive physiology for ten archetypes; encounter scenarios (technologist and intake notes, height estimation, reference sex, smoking, recent medication, quality faults); case assembly; plethysmography and single-breath DLCO tracings; the interpretation engine with 29 fixture cases and a rule-based narrative composer; SVG figures with four-palette export; a lab-style printable report with CSV, TSV and clipboard export; the learner site and a separate quiz and assessment tool (`quiz.html`). `npm test` runs the node tests; the browser harnesses (`benchmarks/ui-smoke.mjs`, `benchmarks/quiz-smoke.mjs`) are run by hand.

Not implemented: NHANES III, FEF25-75 references, TLCO in SI units, replicate DLCO tests, criteria for children, a server, and a language model for free-text feedback.

## Purpose

PFT_Sim generates simulated pulmonary function reports with a known ground truth, lets a learner write an interpretation, and then breaks the case down. Its distinguishing feature is that the same measured values are interpreted under more than one reference equation, and every change in classification is shown, attributed to the measurement that caused it. It is an educational and research tool. It is explicitly uncalibrated, makes no validation claim that has not been run and recorded, and gives no treatment recommendation.

## Stack and repository conventions

The stack matches ARDS_sim so that the two projects build, test, deploy and look alike. This supersedes the TypeScript, Vite and vitest wording in earlier drafts of `CLAUDE.md`. Source is plain ES modules under `src/` with JSDoc typedefs for the data contracts. Tests run with `node --test tests/*.test.mjs`. Node 22 or newer. There are no production dependencies, and the only development dependency is a pinned Playwright for browser harnesses under `benchmarks/`. `scripts/build.mjs` copies `index.html`, styles, local fonts, `src/` and a `.nojekyll` file into `dist/`, and `scripts/serve.mjs` serves it on port 5173 (files are never opened over `file://`, because module workers require HTTP). The two workflows are copies of ARDS_sim's `check.yml` and `pages.yml`, including the pinned runner image and the Node 22 setup. Fonts are local Source Sans 3 and Source Code Pro, copied from ARDS_sim with their OFL notices. Colors come only from `src/styles/tokens.css`; the diastolic grade ramp (`--g0` to `--g4`) belongs to the heart project and is removed.

## Case model

A case is a pure function of a descriptor. The descriptor is `{ v, seed, archetype, severity, technique, age, sex, heightCm, weightKg, hbGdl, group }`, where `v` is the generator version, `seed` is an unsigned 32-bit integer, `severity` is an archetype-specific ordinal, `technique` is the quality modifier described below, and `group` is the self-reported group as it would appear on a requisition. The URL encodes the version, seed and archetype, plus any demographic or severity field the user has overridden. Fields that are not overridden are derived from the seed, so a shared link reproduces the case exactly, and a link with a retired generator version loads under that version's code or states that it cannot. The generator version increments whenever any sampling code, stream order, archetype table or curve family changes.

The pseudo-random generator is a specified, implemented algorithm (sfc32 seeded through a splitmix32 expansion of the seed) with a documented stream order: demographics, then latent physiology, then each maneuver in turn, then measurement noise. `Math.random` is never used. A test asserts that a fixed set of seeds yields byte-identical serialized cases, and that inserting a draw in one stream does not shift the draws of another.

### Ground truth

The ground truth of a case is the set of physical-unit values (liters, liters per second, mL/min/mmHg), the archetype, the severity and the technique modifier. It is not a set of z-scores, because z-scores exist only relative to an equation. The generator needs a reference to anchor latent physiology, and that anchor is a declared, versioned choice stored in the case as `genRef` (GLI Global for spirometry, the volume and TLCO families described below for the others). The interface states plainly that archetypes such as "normal" are normal with respect to the anchor, and that a difference seen under another equation therefore partly reflects the anchor. The anchor is never presented as one of the neutral lenses in the comparison view. The thoracic model in `research/` is not the generator and supplies no reference values.

### Latent physiology and exact constraints

Sampling is constructive, in `src/core/physiology.js`. The variables that define an archetype (for obstruction the FEV1 z-score within a severity band, for restriction the TLC z-score within a band, for low DLCO the DLCO z-score) are drawn uniformly within bands that sit inside the severity thresholds, or from truncated normals by inverse CDF. The remaining variables come from a small factor model (a lung-size, a trapping and a gas-exchange factor plus unique terms) whose loadings are proposals. Values reach liters through the inverse LMS of the anchor equations, `value = M(1 + L·S·z)^(1/L)`. TLC and RV/TLC fix RV and VC; FVC follows as VC × (1 − δ), where δ is the FVC/VC gap, small in health and larger with air trapping; the ratio is sampled, so FEV1 = FVC × ratio and FEV1 ≤ FVC hold exactly; ERV is sampled and FRC, IC follow. There is no accept/reject step against the interpretation engine. Derived quantities are computed, never sampled independently, so the following hold to within floating-point error on every reported quantity and are enforced by property tests over 60 seeds for each archetype and technique level (1,800 cases per run):

FEV1 ≤ FVC for every maneuver and for the reported values. TLC = RV + VC. FRC = RV + ERV. IC = TLC − FRC and VC = IC + ERV. VA ≤ TLC, with VA/TLC lower in obstruction as a modeled effect, not an accident. DLCO = KCO × VA before hemoglobin correction. FVC may differ from slow VC, with FVC ≤ VC permitted and larger gaps in obstruction. The flow-volume loop, the volume-time curve and the tabulated FEV1, FVC, PEF and FEF25-75 come from one curve per maneuver: the tabulated numbers are computed from the curve, not sampled beside it. The curve family has a rise-time and a shape parameter, and a bisection on the rate parameter fixes the curve so that the volume 1.000 s after the back-extrapolated time zero equals the target FEV1 within 1 mL while the volume at the end of the maneuver equals FVC. The curve is `V(t) = A(1 − exp(−a·s(t)^k))` with `s(t) = t − r(1 − exp(−t/r))`; the exponent `k` sets scooping of the loop and `r` the speed of the start. The back-extrapolated zero is the intercept of the tangent at maximum flow. A ratio the family cannot represent is clamped and flagged, never silently altered.

### Maneuver set

A spirometry case contains between three and eight maneuvers, each with FVC, FEV1, PEF, forced expiratory time, back-extrapolated volume (BEV), end-of-test plateau, and flags for the usual technical faults (slow start, early termination, cough in the first second, variable effort, glottic closure). The `technique` modifier, independent of archetype, sets the probability and size of faults. A learner therefore has to decide which maneuvers are acceptable, whether the acceptable ones are repeatable, and whether the grade supports the interpretation, before any equation enters.

Acceptability, repeatability and the quality grade follow the ATS/ERS 2019 spirometry standardization. The reported FVC and FEV1 are the largest values among acceptable maneuvers, taken separately, and FEV1/FVC is computed from those two numbers. The criteria follow Tables 7 and 10 and the end-of-forced-expiration text of Graham et al. 2019, checked line by line against the statement. FEV1 and FVC are judged and graded separately. Both need a BEV below 5% of FVC or 0.100 L, whichever is greater, and no glottic closure in the first second. FEV1 additionally needs no cough in the first second and needs no end-of-test indicator. FVC additionally needs no glottic closure after the first second and needs one of three end-of-forced-expiration indicators: a plateau (under 0.025 L change in the last second), a forced expiratory time of at least 15 s, or an FVC within 0.150 L of, or greater than, the largest FVC in the set. A maneuver that is usable but not acceptable can still supply a value when no maneuver is acceptable, and then the grade is U. Repeatability is the difference between the two largest acceptable values, at most 0.150 L for people older than 6 years, applied to FEV1 and FVC separately. Grades: A for three or more acceptable maneuvers within 0.150 L; B for two within 0.150 L; C for two or more within 0.200 L; D for two or more within 0.250 L; E for a spread above 0.250 L or a single acceptable maneuver; U for none acceptable and at least one usable; F for neither. Up to eight maneuvers are recorded in adults. Not implemented: the criteria for children aged 6 years or younger, leaks, obstructed mouthpieces, faulty zero flow, and the FIVC check after the maneuver. An earlier draft of this section graded the pair of variables together and treated a cough as spoiling both; both were wrong and have been corrected. Constants and their verification states are in `src/core/standards.js`.

Lung volumes carry replicate FRC determinations and DLCO carries replicate tests, each with a repeatability rule from the corresponding ATS/ERS standard (verification state: unverified), so the same logic of reviewing replicates before reading the report applies to all three sections. The shutter-closure panel and the single-breath gas tracings remain later features, but the data model already stores a breath-hold time and an inspired volume for DLCO so that adding the tracing does not change the case schema.

### Archetypes

Ten archetypes are implemented. Every number is a proposal for physician review, not a source-backed value. Severity 1 to 3 selects the z band for the defining abnormality: mild (−2.4 to −1.8), moderate (−3.9 to −2.6) and severe (−5.2 to −4.15) for FEV1 in obstruction, TLC in restriction and mixed disease, DLCO in isolated low DLCO and ERV in obesity.

| Archetype | Defining draws | Other draws |
|---|---|---|
| Normal | ratio z ≥ −1.2, TLC z within −1.3 to 1.6, DLCO z ≥ −1.3 | In 15% of cases one of ratio, TLC or DLCO is set to z −1.25 to −1.45 so that equation choice can matter |
| Obstruction | FEV1 z in the severity band; ratio kept at z ≤ −1.8 | Phenotype from the seed: airway (60%) with normal or raised DLCO, or emphysema-like (40%) with DLCO z falling with severity and a lowered VA/TLC; TLC and RV/TLC rise with severity; 45% respond to bronchodilator |
| Restriction, parenchymal | TLC z in the severity band | RV/TLC near normal, ratio z ≥ −0.8 (mean +0.5), DLCO z mean −1.2 − 0.8 × severity |
| Restriction, extraparenchymal | TLC z in the severity band | RV/TLC raised (z mean +1.5), ERV low, DLCO mildly low, KCO raised because VA is small |
| Mixed | TLC z in the severity band; ratio z in a band that deepens with severity | FEV1 follows from ratio and FVC |
| Nonspecific | FVC z −2.7 to −1.9, ratio z ≥ −0.8, TLC z −1.15 to −0.2 | RV follows as TLC − VC (raised); labeled PRISm when no volumes were measured |
| Low DLCO | DLCO z in the severity band | everything else as normal |
| Anemia | Hb 7.0 to 9.0 g/dL; hemoglobin-adjusted DLCO z −1.0 to 0.5 | measured DLCO is low, adjusted DLCO is normal |
| Obesity, low ERV | BMI 35 to 50; ERV z in the severity band (floor 0.12 L) | TLC mildly low to normal, DLCO normal to raised |
| Bronchodilator, discordant | Obstruction with air trapping (RV/TLC z +1.2 to +4.2, FVC/VC gap 0.10 to 0.18) | Variant from the seed: volume response (FVC rises by 12% to 20% of predicted with little FEV1 change) or technique artifact (FEV1 rises by 12% to 20% of predicted while every post-bronchodilator maneuver stops early, so FVC falls) |

A technique modifier is applied after the archetype. A poor session degrades the measured values and the recorded quality; it does not change the lungs. The archetype's intended pattern agrees with the engine's key under the anchor equations in at least 93% of cases with good technique (at least 96% for normal and 97% for nonspecific), asserted by a test and not enforced by a filter.

**Anchor mismatch, found while building.** The anchor families were derived separately, and their predicted values disagree. GLI Global predicted FVC is 84% to 101% of GLI-2021 predicted VC across ages 20 to 80 and heights 155 to 185 cm (lowest at ages 40 to 60), where in a healthy person FVC is within a few percent of slow VC. Because volumes are sampled first and FVC follows from VC, normal cases have a mean FVC z-score of about +0.7 and FEV1 about +0.8, and VC and FVC z-scores in a single report can differ by about one unit. The generator keeps the physical relationship (FVC slightly below VC) and does not hide the mismatch; it is a property of combining GLI-2021 and GLI Global, and it is stated on the methods page.

## Reference equations

### Per-measurement resolution

Reference values are resolved per measurement, which matches routine laboratory practice. Spirometry is read against a spirometry equation, static volumes against a volume equation, and TLCO against a TLCO equation, and when no equation matching the requested group exists for a measurement, the laboratory uses the closest available one and says so on the report. The interface is therefore:

`resolveReference(measure, { age, sex, heightCm, group }, requestedFamily) → { equationId, matched, fallbackReason, predicted, lln, uln, z, percentPredicted }`

`measure` is one of FEV1, FVC, FEV1/FVC, FEF25-75, TLC, RV, RV/TLC, FRC, ERV, VC, DLCO, KCO and VA. `matched` is false whenever the requested group or family could not be honored, and `fallbackReason` is a fixed-vocabulary string such as `no-group-specific-equation` or `age-outside-range`. Every report line shows its equation identifier, and every fallback is visible on the line, not in a footnote.

### Families

The spirometry families are GLI-2012 (group-specific), GLI Global 2022 (group-neutral) and NHANES III. Static volumes use GLI-2021 and TLCO uses GLI-2017. The published titles of the GLI-2021 static volume standard and the GLI-2017 TLCO standard restrict both to people of European ancestry, because data from other groups were insufficient (confirmed from titles and abstracts returned by search, not from the full texts). The fallback is therefore the usual path for lung volumes and TLCO in any case whose requisition group is not White: the European equation is applied, the line says so, and the report states that the equation was not derived in the patient's group. The group coverage, age range and sex handling of each family are still entered in `src/reference/coverage.json` from the primary publications, with a verification state, before the fallback table is written.

### Comparison and reclassification

The comparison view evaluates the same measured values under each selected combination. Reclassification is computed per family and attributed: the output records which measurements changed their low, normal or high label, the resulting change in the overall pattern, and the equation change responsible. A change in the final pattern label is never shown without the measurement-level cause. Borderline cases, defined as a z-score within a configurable band of the lower limit (default 0.25 z, to be confirmed), are flagged whether or not they flipped.

The interpretation logic accepts z-scores from different sources. A pattern built from spirometry under one family and TLC under another is a legitimate laboratory output, and the report states that the pattern rests on more than one reference.

### Implementation and test vectors

Reference values are implemented from the published equations and published lookup tables, not by translating the `rspiro` source. `rspiro` is licensed GPL (version 0.5 on CRAN lists GPL-2 or GPL-3), and copying its code into this MIT-licensed repository would create a licensing problem, whereas using it only to generate numeric test vectors does not. `scripts/make-vectors.R` generates CSV vectors with `rspiro` over a grid of age, sex, height and group (including edge ages), and `tests/reference.test.mjs` asserts agreement of predicted value, LLN and z-score. The tolerance is set when the tables are ported, because it depends on the precision of the shipped coefficients and spline tables. It is recorded in the test, not guessed here. The R script prints `sessionInfo()` into the vector file header so that the vectors are reproducible, and each argument convention of `rspiro` is checked against its documentation before the vectors are trusted.

### Terms of use for the GLI tables

The terms are not yet settled, and this is what is known. The summary supplied for this project states that the equations and lookup tables are freely available for implementation, that official GLI software is restricted to research, education, training and validation and is not approved for direct patient treatment, that distribution is under a CC BY-NC license, and that the programmatic API needs keys from the ERS. That summary rests partly on vendor and aggregator pages, and the claim that matters most (the license that governs the lookup tables) is the one that could not be confirmed: the ERS pages were unreachable from the build environment when this revision was written, and a web search surfaced only a CC BY-NC license on an unrelated 2025 paper and the statement that the equations need spline tables, not the terms for the tables. Treat the CC BY-NC statement as unverified until someone reads the ERS terms directly. A second attempt in this revision to reach `gli-calculator.ersnet.org/docs.html` and the ERS pages also failed (the environment's network policy does not resolve those hosts), so the status is unchanged. The `docs.html` page is an API reference and, as the project physician noted, is not the license.

If the tables are CC BY-NC with attribution, three consequences follow. The public repository can host them only with attribution and a notice that they are non-commercial, the repository's MIT license cannot be allowed to read as covering them, and the tables belong in their own directory with their own `NOTICE` file. Anyone who reuses the tool commercially would need ERS permission, which the README must say. No browser code may call the ERS API, because the site is static and a key shipped to the client would be exposed, so the tool uses ported tables only. Until the primary terms are read and recorded here, no table is committed; only vector files generated by `rspiro`, containing derived numbers and no coefficients, are acceptable, and even those should be confirmed with the same terms in hand. The educational disclaimer in the footer already matches the restriction against direct patient treatment.

### Port status, 2026-10-20

The reference module is implemented in `src/reference/gli.js` over JSON extracted by `tools/extract-gli.py` from the five GLI workbooks the project physician supplied (URLs, sizes and sha256 values in `src/reference/sources.json`; the script refuses inputs whose hash differs). Covered: GLI-2012 spirometry for ethnicity codes 1 to 5, GLI Global 2022 spirometry, GLI-2021 volumes (TLC, RV, VC, IC, ERV, FRC, RV/TLC) and GLI-2017 TLCO in traditional units (DLCO, KCO, VA). Not covered: FEF25-75 and the other GLI-2012 flow measures, TLCO in SI units, NHANES III, and the hemoglobin correction for DLCO.

Agreement with rspiro 0.5 on the 2,664 spirometry vectors: GLI Global matches to floating-point precision (about 1e-15 relative for predicted value and LLN). GLI-2012 differs by up to 2.07e-4 relative in predicted value, 2.40e-4 in LLN, and 1.70e-3 in z-score at 80% of predicted, uniformly across ethnicity codes. The pattern (a constant offset in ln M independent of height and age) is consistent with the workbook's coefficients being rounded, for example a0 = -10.342 for male FEV1, while rspiro appears to carry more digits; this explanation is inferred, not confirmed against rspiro's source. Both are far inside the 2% ceiling, and the test fails if either exceeds these recorded values.

Cross-check against the independent implementation in pft_interpreter (`tools/crosscheck-interpreter.mjs`): all 24 Global spirometry coefficient sets (M and S, six measure-sex pairs) are identical, and every spline table agrees to within 5e-5, which is the rounding of its 4-decimal tables. pft_interpreter also selects the nearest whole-year row of the table, where this module interpolates linearly between the 0.25-year rows, so its values at non-integer ages differ slightly from the published tables.

Open items for the port. The regression coefficients for GLI-2021 volumes and GLI-2017 TLCO are not in the supplied workbooks; they were read from pft_interpreter and have no independent check, so rspiro vectors for TLCO and volumes (if the package provides them), or the coefficient tables from Hall 2021 and Stanojevic 2017, are still needed. The vectors cover whole-year ages only, so linear interpolation at fractional ages is untested against rspiro; the next vector grid should include fractional ages such as 33.4 and 61.75. The exact ERS license wording is still to be pasted into `src/reference/NOTICE`.

### Encounter scenarios

A case can carry encounter scenarios (`src/scenarios/`, model and every effect size in `docs/scenarios-model.md`). A scenario changes the measurement process or an input the laboratory enters; it never edits the lungs, so `case.truth` is the same with and without scenarios. The descriptor gains optional `scenarioLevel` (none, light, moderate, heavy: 0, 1, 2, and 3 or 4 scenarios) and `scenarioIds`, carried in the link as `sc` and `si`. A link without them reproduces the case it always did, which a test checks by SHA-256 hash against 50 cases generated before the layer existed, so the generator version stays 1. Selection draws only from the `scenarios` stream; scenario maneuver faults draw from `scn-<set>-<i>` streams after the technique faults of the same maneuver.

The catalog holds 63 entries drawn from `docs/research/scenarios.md` (medication and tobacco before the test, preparation and clinical state, height estimated from arm span, ulna or an old chart, reference sex and requisition group, interface and cooperation problems, spirometry, bronchodilator-study, DLCO and plethysmography technique). The laboratory enters the stated height and the reference sex while the lungs were generated from the true height and birth sex; the key is computed from what the laboratory entered. New maneuver faults (leak, tongue or teeth at the mouthpiece, pause at TLC, submaximal effort) follow the 2019 criteria already coded, with the simulator rules for usable-versus-acceptable and for a pause longer than 2 s marked as such in `quality.js`. Acute effects and carboxyhemoglobin act through `applyAcuteEffects` and `cohbDlcoFactor` in `physiology.js`. Every effect size is an unverified simulator choice; only directions come from the research catalog, and its "Unverified or conflicting" section decides what text may state as fact. Numerical check recorded: 500 cases at each level pass the exact constraints, and the constraint sweep reports zero violations at every level (`node tools/constraint-sweep.mjs 300 heavy`).

`case.scenario` carries the statements, technologist comments, caveats with weights, decoy caveats, pre-test record, stated and true height, reference sex used and its alternative, and carboxyhemoglobin. `interpret()` copies `report.caveatIds` into `key.caveatIds`; no other key field changed.

## Interpretation module

`src/interpret/interpret.js` implements the ATS/ERS 2022 interpretive strategy as coded here, with the lower limit of normal at z = −1.645 and the upper limit at +1.645. It is a pure function of the reported values and the resolved references and returns a structured key: pattern, severity, per-measurement labels, bronchodilator result under two rules, DLCO category and subtype, flags, session-quality qualification, and the equation provenance of every input. Classification uses z-scores only; percent predicted is displayed and never classifies. The key is computed from the values on the report, after maneuver variability and technique faults.

Pattern logic, in order. No FEV1 or FVC: not interpretable. Ratio below the limit: with TLC measured, TLC below the limit is mixed and otherwise obstruction; without TLC, a low FVC gives obstruction with low FVC (volumes needed) and otherwise obstruction. Ratio at or above the limit and TLC below the limit: restriction, even with normal spirometry. Ratio at or above the limit with a low FVC or a low FEV1: nonspecific when TLC is measured and not low, preserved ratio with impaired spirometry (PRISm) when TLC is not measured. Otherwise normal. Hyperinflation (TLC above the upper limit), air trapping (RV or RV/TLC above the upper limit) and low ERV are flags, not patterns; low ERV is reported with the BMI.

Severity is graded from the FEV1 z-score (mild above −2.5, moderate −2.5 to −4.0, severe below −4.0) and scored only for obstruction and obstruction with low FVC. For restriction, mixed, nonspecific and PRISm patterns the engine reports a band per measure and does not score severity, because whether the 2022 statement grades these by FEV1 or TLC has not been read. The bronchodilator response is reported under the 2022 rule (change in FEV1 or FVC above 10% of the predicted value) and under the earlier rule (at least 12% of baseline and at least 200 mL), and the key scores the 2022 rule. Diffusing capacity is read on the hemoglobin-adjusted value: reduced, normal or raised by z-score, with a subtype from VA and KCO (low KCO with preserved VA; low VA with raised KCO; low VA with normal KCO; both low). Equation comparison runs the same report under GLI-2012 (by requisition group) and GLI Global and attributes each label change to the spirometry measurement that moved. A session whose FEV1 or FVC grade is D, E, U or F qualifies the key.

The fixture file `tests/fixtures/interpretation-cases.json` holds 29 hand-built cases (every branch above, the bronchodilator disagreements in both directions, the low-ERV and DLCO subtypes, and the not-interpretable and poor-quality cases) run against a linear fake reference so each z-score is exact. The expected outputs are my reading of this section and are provisional until the project physician reviews them.

**Unverified constants and definitions.** The 2022 severity bands and their boundary rule (the sources read leave a gap between −1.645 and −1.65), the 10% bronchodilator threshold and whether the boundary is inclusive, the definitions of air trapping and hyperinflation, severity for DLCO, and the Cotes hemoglobin correction (DLCO × (10.22 + Hb) / (1.7 × Hb) for men aged 15 and over, 9.38 in place of 10.22 for women and children; Hb in g/dL) have not been compared with the primary statements. Each is marked in `src/core/standards.js` or in the engine output, and the learner site states it on the case.

## Consultation record

CLAUDE.md requires a consultation with Claude Opus 5.5 at high reasoning before substantive physiology, interpretation or learner-interaction changes, and a critical record of what was accepted. The reviewer read SPEC.md, the core modules and the reference module and did not have the 2022 statement, so its statements about that document are from memory and were treated as leads to verify.

Accepted: constructive sampling in the coordinates where criteria are defined, with no filter against the engine, because a filter makes the key agree by construction, cannot catch an engine bug, and clusters fallback cases where acceptance is lowest. The key is computed from reported values, with the archetype shown as ground truth; agreement is a property test. The normal archetype should show occasional isolated borderline values rather than being clean. The volume model was overdetermined (FVC set twice, ERV never sampled) and was rebuilt: TLC, RV/TLC and ERV are sampled, and VC, FRC, IC and FVC are derived. Demographics now follow the archetype (BMI 35 to 50 for obesity, Hb 7 to 9 g/dL for the anemia variant), and the severity ladder was cut to three levels. PRISm was renamed: the archetype is the nonspecific pattern, and PRISm is its spirometry-only label. Low ERV is a finding and not a pattern, so it cannot hide another pattern. The bronchodilator rules disagree in both directions and the 2022 rule depends on the reference equation, so the comparison view reports it. The discordant bronchodilator archetype was redefined (a volume response, and a post-bronchodilator technique artifact), and the FEV1-and-FVC-rise-together variant was dropped because it is ordinary. The extraparenchymal restriction archetype was given a raised RV/TLC and a low ERV. An isolated-low-DLCO variant caused by anemia was added. Borderline answers are accepted when they match the other equation, the anchor disclosure appears on the case, the flow-volume predicted and lower-limit envelopes are labeled schematic and hidden by default, and unverified constants are stated on the case and not only on the methods page.

Modified: the reviewer suggested a hand-built correlation matrix be replaced by a factor model; the generator uses a small factor model, but its loadings are guesses and are labeled so, since no dataset gives joint z-score correlations across the three GLI families. The reviewer proposed property-testing that VC, IC, FRC, ERV and KCO z-scores are approximately N(0,1) in the normal archetype; the test cannot pass as stated because of the anchor mismatch recorded above, so the mismatch is documented and the distributions are inspected but not asserted. The reviewer's suggestion to implement the hemoglobin correction only after verification was not followed: the formula is implemented and flagged, because leaving the Hb field unused would remove the anemia case, and the physician can verify it against the 2017 standard in minutes.

Not accepted: scoring severity for restriction by TLC or FEV1 (left unscored until the statement is read), and enlarging the normal archetype to the reviewer's estimate of one in five to one in three healthy people with at least one low value (kept at 15% borderline, none below the limit, so a normal case reads as normal).

## Report and figures

The report table lists every measurement with measured value, unit, predicted, LLN, z-score, percent predicted, a text flag (low, high, borderline) and the equation identifier. A measurement for which only the European equation exists shows "European equation applied" on its line. Flag color is text only, never a fill. The maneuver table shows each attempt with FVC, FEV1, ratio, PEF, FEF25-75, FET, BEV, last-second volume change and the technologist's comment on technique faults. Whether each maneuver is acceptable or usable is hidden until the learner checks answers, because acceptability and grading are questions.

Figures come from a registry (`src/ui/figures/`) of pure functions `render(data, { palette })` that return self-contained SVG with inline colors from one of four palettes (dark panel, white panel, transparent with dark ink, transparent with light ink); the page draws the dark palette and `src/ui/svg-export.js` produces all four for download or copy. The flow-volume figure plots expiration up and inspiration down with 2 L/s drawn as long as 1 L, overlays every maneuver, overlays the post-bronchodilator set in the second series color when it exists, and after checking draws unacceptable maneuvers muted (before checking every maneuver has the measured color, so the page does not reveal acceptability). The inspiratory limb (`src/core/inspiratory.js`) is a display-only smooth shape in the same exhaled-volume coordinate: a good maneuver closes the loop (FIVC within max(0.100 L, 5% of FVC) of FVC, the 2019 criterion); a leak or mouthpiece obstruction always, and early termination, glottic closure, variable effort, cough and slow start with stated probabilities, give an incomplete loop; variable effort also varies peak inspiratory flow and shape between maneuvers. Its peak flow rule (2.2 + 0.62 x FVC L/s, bounded 1.8 to 8) and the incompleteness probabilities are unverified teaching choices. Fault artifacts in the plotted expiration (cough spikes, glottic closure, leak, mouthpiece obstruction, variable-effort descent shape, and a time-warp slow start only when the curve is not already slow) are added as zero-net-volume changes, so the plotted FVC and the volume at FEV1 time equal the tabulated values; the tabulated PEF, FEF25-75 and plateau are not recomputed from them, so those can differ slightly from the drawn trace (visual only). Predicted and lower-limit curves are schematic, built from the predicted and lower-limit FVC and FEV1 and not from a published loop, labeled as such and hidden unless requested. The volume-time plot starts 4 s before time zero with a synthetic tidal baseline and deep inspiration (visual only), and shows the best maneuver, the tangent at peak flow, the back-extrapolated time zero, the FEV1 mark, the BEV, and the volume change in the last second; the post-bronchodilator best maneuver is overlaid when present. The z-score strip shows each index (FVC, FEV1, FEV1/FVC and, when measured, TLC, DLCO, VA, KCO) on an axis from -5 to +3 with the LLN (z = -1.645) and predicted value marked and a large marker at the z-score; position relative to the limit is stated in text only. Series color encodes the quantity; dash style encodes the relation (measured solid, predicted dashed, lower limit dotted).

## Learner site

`index.html` and `src/app/` form a static, framework-free page with a Practice view and a Method and limits view. A new case is drawn at random from a weighted archetype mix (a teaching mix, not prevalence), with selectable test quality and panel (full, or spirometry only). The link carries the descriptor as an opaque base64url code, so the archetype is not in the address bar; this is a convenience, not security, and the key is present in the page code. A plain descriptor link (`?v=1&s=…&a=…`) opens the same case for instructors.

The learner reads the demographics (including the group on the requisition), the maneuvers, the figures, the spirometry table under a selectable equation (GLI Global or GLI-2012), the bronchodilator study when done, lung volumes and diffusing capacity, then answers six structured questions: pattern, severity of obstruction, FEV1 quality grade, FVC quality grade, bronchodilator response under the 2022 rule, and diffusing capacity. Answers are held in the page and scored against the key for the displayed equation; an answer that matches the key under the other equation is accepted and labeled. The reveal gives the score, the teaching text for the pattern (physiology first, no case values), the bronchodilator rules and why they disagree, session quality with the grade definitions, the same spirometry under GLI-2012 and GLI Global with every reclassification, and the ground truth with the anchor disclosure.

The Method and limits view lists what is simulated, what is not, and every rule that has not been checked against its primary source, and carries the GLI attribution and license summary.

## Feature rollout (integration record)

Six threads built the second release in parallel worktrees against `docs/ARCHITECTURE-NEXT.md`; each thread's own model document is the source for its constants: `docs/pleth-dlco-model.md`, `docs/scenarios-model.md`, `docs/narrative-model.md`; research inputs are in `docs/research/`.

Integration decisions made in `src/core/case.js`. The plethysmography tracings own the reported FRC: it is the mean of the acceptable trials (replicate agreement 5% for grades A and B, 10% for grade C, from a secondary table), centered on the FRC after any scenario effect; ERV and IC are kept and TLC, RV and VC follow, so the exact identities hold. When a technical fault changes the physics of the single-breath test (low inspired volume, Valsalva, Mueller, a poor sample) the laboratory reports what the test measured, so the tracing's recomputed DLCO and VA replace the case values. Scenario fault names are translated to the tracing builders' forced-fault ids. The inspiratory limb is generated by the figures from the exhaled volume with a seeded stream; it is not stored on the case. Technique now changes FRC, TLC and RV (through trial scatter) but not the patient or the true physiology. The scenario-regression hashes were regenerated for the integrated generator; with scenario level 'none' the pre-scenario spirometry, volumes and DLCO are unchanged apart from the FRC and DLCO effects above. A seed sweep of 8,000 cases at level 'none' and 5,000 at level 'heavy' found no constraint violations.

Known simplifications that matter to learners: the inspiratory limb and the tidal baseline are synthetic; cough artifacts are zero-net-volume and do not recompute PEF; only one DLCO test is simulated, so no replicate rule applies; the slow-start scenario cannot reach the back-extrapolated-volume limit in the curve family and rounds the loop instead; FIVC is not used in the acceptability rules; the quiz's exam code is not tamper-proof (the key is computable in the browser; a server would be needed for secure assessment); half credit for adjacent severity bands or grades and the precision-recall scoring of the limitations item are project conventions, labeled as such. Effect sizes in the scenario catalog (including arm-span divisors, the ulna ratio, the COHb reference and DLCO effect per percent COHb, the acute effects of smoking, medication and exercise) are unverified and carry that label in the model documents.

## Acceptance criteria for v0.01

The same descriptor yields byte-identical serialized cases on repeated runs and across the supported Node versions. Zero constraint violations over a seed sweep (`tools/constraint-sweep.mjs`). The sweep of 15,000 cases (1,500 seeds for each of ten archetypes, technique cycling through good, fair and poor) found two violations of TLC = RV + VC, caused by a floor on RV in the report; the floor was replaced by a cap on ERV, and the rerun found none. The earlier target of 100,000 seeds per archetype and technique level has not been run. The volume 1.000 s after the back-extrapolated zero on every maneuver curve equals the tabulated FEV1 within 1 mL, and the curve integral equals FVC within 1 mL. Reference outputs agree with the `rspiro` vectors within the tolerance recorded at port time. Every branch of the decision table has at least one fixture case, and the engine reproduces the expected key for all of them. Reclassification output for a hand-built pair of equations changes only the measurements it should and attributes each change correctly. The build is deterministic, `npm test` and `npm run build` pass in CI, and browser QA harnesses pass in both themes and at a phone width.

## Research track

`research/thorax_sim.py` and its design document remain as an unreferenced research scaffold. They are not used for reference equations, not imported by the product, and not a source for any value in it. The prior-predictive run with placeholder priors reproduced neither the direction nor the age pattern of the between-group differences in GLI predicted values, and because every group-specific chest offset is an unsourced placeholder, the reported interval describes the priors and not anatomy. Anthropometric differences between self-reported groups are also shaped by early-life nutrition, altitude, air pollution and socioeconomic position, so a gap the model fails to explain cannot be attributed to ancestry. The defensible output is the portion of a difference in predicted values that body proportions fail to account for. Moving this track to its own repository is recommended and is listed as an open decision.

## Decisions

Settled by the project physician. The self-reported group is shown to learners as it would appear on a requisition. The borderline band keeps its default of 0.25 z. Structured learner answers ship in every version. The research track stays in this repository, unreferenced by the product. Agreement with `rspiro` on predicted values has a ceiling of 2% relative difference. A correctly ported equation should match `rspiro` to within rounding of the published coefficients, so a 2% tolerance would also pass a transcription error in a spline table or coefficient; the test therefore records the observed maximum difference per equation and fails on any increase over the value recorded when the port was verified, with 2% as the outer limit.
