# Report page and figure redesign: plan and thread contract

Teaching simulator only. Revised after the Opus 5.5 consultation (recorded at the end). This file is the contract between the parallel threads.

## Why

The individual figures read as stand-alone plots, not as parts of a laboratory printout. The deployed site was compared with `docs/research/report-formats.md` (ATS 2017 standardized report, one Vitalograph printout). No Vyaire, MGC, COSMED or Medgraphics printout was obtained, so statements about vendor displays that are not in that note are tagged MEM (from memory) and stay unverified until a printout is seen.

Defects found in the rendered figures: all 3 to 8 replicate expiratory curves overlaid with no way to separate them; inspiratory limbs that end in vertical spikes and an expiratory limb that drops vertically into inspiration while flow is still about 0.14 L/s; a schematic LLN loop that no laboratory draws and that cannot be defined (the 5th percentiles of PEF, FEF50 and FVC do not occur in one person); a decoy wave drawn as tidal breathing before the forced maneuver; filled circle markers at FEV1 with drop lines; a shutter display whose trial labels collide; a Raw loop with kinks at every flow reversal and an upper-limit line that dominates it; no volume-time record of the plethysmography maneuver; no partition of RV, ERV and IC; no airway-resistance rows in the report; a z-score strip with a filled circle where the ATS 2017 sample uses a large star; a report that is one long column inside the practice page.

The student copy renders no answer-key text; the descriptor and key remain computable in the browser, so this is a presentation boundary, not a security one, and the page says nothing more than that. ## Separable loops

When a figure holds several maneuvers or trials (3 to 8 spirometry efforts before and after the bronchodilator, 3 or more panting trials, replicate DLCO tests), the learner can separate them. Every panel takes `view: 'best' | 'all' | 'separate'` and `selected: number[]` (1-based). `best` draws the best curve only (the report default); `all` overlays the selected ones in distinct tints with the best emphasized; `separate` draws one small panel per maneuver or trial (same axes, number, value and fault comment under each). The practice page shows numbered chips that toggle each maneuver and a view switch; SVG downloads follow the view. Rejected or unacceptable maneuvers are marked only after the answers are checked. The report page prints `best`.

## Physiology constraints

Every value in `case.report`, every FRC (trial and reported), TLC, RV, VC, DLCO and spirometry value stays bit-identical. `src/core/pleth.js` recomputes sRaw, Raw and sGaw from the plotted arrays, so reshaping the Raw loop changes them: that is accepted and declared. The hashes for the resistance values are regenerated once, by the integrator, with the reason recorded in `SPEC.md`; nothing else in the hash fixture may change.

Rules for PLETH:
- New random stream labels for every display-only trace (for example `pleth-timeline`); never draw from an existing stream.
- The volume-time record embeds each trial's `t`, `pm` and `pbox` arrays verbatim, not resampled; during closure the pneumotach volume is flat.
- The kinks come from half-sine breaths with Ti different from Te and a `tau*dv` term that jumps at every zero crossing, and from `expFlat` and `|v|` switching at v = 0. Generate each breath as one phase-continuous cycle with a smooth inspiratory and expiratory asymmetry, blend expiratory resistance with tanh(v/eps), and model loop opening as a quadrature term h*cos(theta) symmetric about the fit line so it does not bias the regression.
- Resistance loop morphologies, parameterized and each with a source note marked verified, secondary or MEM: closed near-linear (normal), golf-club (flow limitation: inspiratory limb near linear, expiratory limb bends toward the shift-volume axis, loop opens), steep closed loop (restriction), sigmoid (central or extrathoracic obstruction only). The frequency-dependent phase-lag model is deferred.
- Name the resistance estimator next to sRaw on the figure and the report (the code fits a regression over |flow| at most 0.5 L/s; vendors report sRtot, the line between the points of maximal shift, or sReff, and these diverge in open loops). Breathing mode is stated as tidal (the code uses VT 0.85 L, Ti 1.3 s).
- Raw = sRaw divided by the reported FRC (the mean of the trials); state it.
- If the shutter closes off the end-expiratory level (`eelShift`), the record shows the offset.
- Derive RV/TLC and every ratio from unrounded values; round only for display.
- If a target slope must be exact despite noise, build the noise orthogonal to x.
- Tag unverified clinical constants as in `src/core/standards.js`; document the model in `docs/pleth-dlco-model.md` and the numerical identity check in `SPEC.md` terms (the integrator pastes it).

## Threads and file ownership

Each thread works in its own git worktree, first merges `origin/claude/tender-davinci-4afrwf`, edits only its files, commits, and does not push. Nobody edits `src/ui/figures/index.js`, `SPEC.md`, `tests/fixtures/baseline-case-hashes.json` or the shared helpers `src/ui/figures/svg.js`, `traces.js` and `fig-a-kit.js` (the integrator owns them; a thread needing a change in a shared helper writes the helper into its own file instead and reports the request).

| Thread | Owns | Does |
|---|---|---|
| SPIRO | `src/ui/figures/panel-spirometry.js`, `flow-volume.js`, `volume-time.js`, `tests/panel-spirometry.test.mjs`, `tests/flow-volume*.test.mjs` | Spirometry panel; repairs the listed defects; best, all and separate views |
| PLETH | `src/ui/figures/panel-pleth.js`, `pleth-shutter.js`, `pleth-raw.js`, `volume-bars.js`, `src/core/pleth.js`, `docs/pleth-dlco-model.md`, pleth tests | Pleth panel, timeline trace, Raw morphologies, numerical identity check; exports `volumeBars(data, { palette, width, height })` |
| SUMMARY | `src/ui/figures/panel-dlco.js`, `dlco-trace.js`, `z-strip.js`, `src/ui/figures/z-inline.js`, tests | DLCO panel and validity strip, z-strip star and stacking, ULN line, inline z graphic (`zInline(measure, { z, lln, uln }, { palette, width, height })` returns an SVG fragment) |
| PAGE | `report.html`, `src/report-page/*`, `src/report/html.js`, `src/report/model.js`, `src/report/report.css`, `scripts/build.mjs`, `benchmarks/report-smoke.mjs`, tests | The separate page, the three-page print layout, airway-resistance rows in the model, student and instructor copies, links from `index.html` and `quiz.html` (the only edits there), preview link in the practice report tab |

Panel interface: `render(data, { palette, width = 672, height, title, description, showQuality = false, view = 'best', selected })`; `dataFor(caseData)` returns null when the case lacks the test. A panel is one `<svg>` whose sub-plots are `<g data-subplot="...">` groups. Frozen typedefs for new data (`PlethTimeline`, `PlethRawLoop`) are written by PLETH into its first commit, and PAGE reads them there. PAGE develops against the existing figures and the typedefs, and the integrator swaps in the panels. Downloads of panels as SVG and CSV or HTML on the report page are deferred; print and PDF come first, and the practice page keeps its downloads.

## Acceptance

`npm test` and `npm run build` pass. `benchmarks/report-smoke.mjs` loads `report.html` for six cases (normal, obstruction with post-bronchodilator, restriction, mixed, spirometry only, full panel with a heavy scenario) at desktop and 390 px (scale-to-fit, no horizontal page scroll), prints to PDF with at most three pages for the student copy, and finds no answer-key text in the rendered student page. Panel SVGs in all four palettes are well formed and self-contained. The integrator inspects rendered PNGs of every panel and the three printed pages.
